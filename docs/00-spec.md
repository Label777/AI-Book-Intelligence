PROJECT: AI BOOK INTELLIGENCE

Платформа интеллектуального анализа книг с помощью искусственного интеллекта

1. ГЛАВНАЯ ИДЕЯ

Создай современную AI-платформу, в которой пользователь вводит название книги и автора, а искусственный интеллект автоматически создает полноценную презентацию книги, включающую:

* Глубокое саммари книги.
* Анализ ключевых идей.
* Разбор глав.
* Основные концепции и теории.
* Практические выводы.
* Примеры применения идей в реальной жизни.
* Критический анализ книги.
* Визуальные схемы и интеллект-карты.
* Итоговую презентацию, которую можно изучать как полноценный образовательный материал.

Цель продукта: позволить человеку получить максимум ценных знаний из книги в удобном визуальном формате, не читая сотни страниц.

2. ПОЛЬЗОВАТЕЛЬСКИЙ СЦЕНАРИЙ

1. Пользователь открывает сайт.
2. Вводит название книги и автора.
3. AI определяет нужную книгу и предлагает подтвердить найденное издание.
4. Пользователь нажимает «Создать анализ».
5. AI собирает доступные достоверные сведения о книге.
6. Создается структурированная презентация.
7. Пользователь изучает материал через интерактивный интерфейс.

Добавь возможность загрузить EPUB, PDF или TXT, если пользователь располагает собственной копией книги.

Если полного текста книги нет, не выдавай предположительные детали за содержание оригинала. Четко обозначай, какие выводы основаны на доступных источниках, а какие являются аналитической интерпретацией AI.

3. СТРУКТУРА ПРЕЗЕНТАЦИИ

Каждая книга должна превращаться в презентацию из следующих разделов:

Слайд 1. Обложка

* Название книги.
* Автор.
* Год публикации, если известен.
* Категория.
* Главная идея книги в одном предложении.
* Визуальная обложка.

Слайд 2. О чем эта книга?

* Основная проблематика.
* Что хотел донести автор.
* Какую проблему решает книга.
* Кому будет полезна.

Слайд 3. Главные идеи

* 5–10 важнейших идей.
* Объяснение каждой простым языком.
* Почему они важны.

Слайд 4. Разбор по главам

* Название каждой главы.
* Краткое содержание.
* Основные тезисы.
* Главный вывод.
* Связь с предыдущими и последующими главами.

Слайд 5. Ключевые концепции

* Главные теории.
* Авторские модели.
* Методики.
* Принципы.
* Визуальные схемы.

Слайд 6. Самые ценные инсайты
Выдели 10 наиболее ценных мыслей книги. Для каждой:

* Суть.
* Объяснение.
* Пример из жизни.
* Почему это может изменить мышление человека.

Слайд 7. Практическое применение

* Что можно внедрить уже сегодня.
* Конкретные действия.
* Пошаговые инструкции.
* Примеры применения в работе, бизнесе и повседневной жизни.

Слайд 8. Психология и философия автора

* Как автор смотрит на мир.
* Какие убеждения лежат в основе книги.
* Какую модель мышления предлагает автор.

Слайд 9. Критический анализ

* Сильные стороны книги.
* Слабые стороны.
* Спорные утверждения.
* Недоказанные гипотезы.
* Что устарело.
* Какие идеи противоречат современным исследованиям.

Слайд 10. Связь с другими знаниями

* С какими теориями пересекается книга.
* Какие другие книги дополняют ее.
* Какие идеи можно объединить.

Слайд 11. Главные выводы

* 10 выводов, которые стоит запомнить.
* Одна главная мысль.
* Что читатель должен вынести из книги.

Слайд 12. План внедрения
Создай персональный план применения знаний:

* Первые 24 часа.
* Первые 7 дней.
* Первые 30 дней.

Количество слайдов может динамически увеличиваться в зависимости от объема и сложности книги.

4. AI-АНАЛИТИКА

Создай отдельный интеллектуальный модуль, который оценивает книгу по следующим параметрам:

* Глубина идей.
* Практическая ценность.
* Оригинальность.
* Достоверность аргументации.
* Актуальность.
* Сложность восприятия.

Для каждой оценки предоставляй объяснение. Не выдавай субъективные оценки за объективные научные рейтинги.

Дополнительно AI должен определять:

* Самую сильную идею книги.
* Самую недооцененную идею.
* Самую спорную идею.
* Идею с наибольшим потенциалом практического применения.

5. ИНТЕРАКТИВНЫЕ ФУНКЦИИ

Добавь:

1. AI Book Chat — пользователь задает любые вопросы по книге.
2. Explain Like I’m 5 — объяснение сложных концепций максимально простым языком.
3. Deep Dive — углубленный анализ выбранной идеи.
4. Quiz Mode — создание теста по содержанию книги.
5. Flashcards — карточки для запоминания ключевых идей.
6. Mind Map — интерактивная карта всех основных концепций.
7. Compare Books — сравнение двух или нескольких книг.
8. Personal Action Plan — создание плана внедрения знаний.
9. Listen Mode — озвучивание саммари.
10. Bookmark — сохранение понравившихся идей.

6. ДИЗАЙН И UX/UI

Создай дизайн уровня премиального образовательного SaaS-продукта.

Визуальное направление:

* Минимализм.
* Темная и светлая темы.
* Современная типографика.
* Большое количество свободного пространства.
* Качественные иллюстрации.
* Аккуратные анимации.
* Плавные переходы.
* Визуально насыщенные презентации.

Референсы по качеству интерфейса:

* Notion.
* Linear.
* Readwise.
* Gamma.
* Apple.

Главная страница должна содержать:

* Большой заголовок с описанием продукта.
* Поле поиска книги.
* Кнопку генерации.
* Примеры готовых презентаций.
* Популярные книги.
* Библиотеку пользователя.

7. ТЕХНИЧЕСКАЯ АРХИТЕКТУРА

Продумай архитектуру с учетом масштабирования.

Предусмотри:

* Frontend.
* Backend.
* AI API.
* Базу данных.
* Авторизацию.
* Хранение пользовательских библиотек.
* Загрузку файлов.
* Систему генерации презентаций.
* Кэширование результатов.
* Экспорт презентаций в PDF.
* Адаптивную мобильную версию.

Раздели AI-генерацию на отдельные этапы:

1. Идентификация книги.
2. Сбор и проверка источников.
3. Анализ структуры.
4. Генерация саммари.
5. Глубокий аналитический разбор.
6. Создание визуальных материалов.
7. Формирование презентации.
8. Проверка фактической точности.

Не создавай один огромный AI-запрос для всей работы. Используй многоэтапную генерацию с сохранением промежуточных результатов.

8. КАЧЕСТВО КОНТЕНТА

Это критически важная часть проекта.

Запрещено:

* Выдумывать содержание глав.
* Приписывать автору несуществующие цитаты.
* Выдавать общие рассуждения за глубокий анализ конкретной книги.
* Повторять одну мысль разными словами ради объема.
* Создавать поверхностные саммари.

Каждый раздел должен давать реальную интеллектуальную ценность.

Разделяй:

* Факты из книги.
* Интерпретацию AI.
* Внешние исследования.
* Собственные критические выводы.

Учитывай авторские права: не воспроизводи большие фрагменты защищенных книг. Создавай оригинальные аналитические пересказы.

9. ЭТАПЫ РАЗРАБОТКИ

Работай последовательно:

Этап 1 — исследование продукта и конкурентов.

Этап 2 — UX/UI и проектирование интерфейса.

Этап 3 — архитектура и выбор технологий.

Этап 4 — разработка главной страницы.

Этап 5 — система поиска и идентификации книг.

Этап 6 — AI-движок анализа книг.

Этап 7 — интерактивная презентация.

Этап 8 — дополнительные AI-инструменты.

Этап 9 — экспорт, авторизация и библиотека.

Этап 10 — тестирование, оптимизация и запуск.

10. ПРАВИЛА РАБОТЫ CLAUDE CODE

Не пытайся реализовать все одновременно.

Сначала проведи исследование, предложи архитектуру и составь технический план.

После этого реализуй проект поэтапно.

Перед началом каждого этапа:

* Определи задачи.
* Проверь зависимости.
* Определи критерии готовности.

После каждого этапа:

* Проведи тестирование.
* Проверь адаптивность.
* Исправь обнаруженные ошибки.
* Обнови документацию.

Не оставляй кнопки без функциональности.

Не используй случайные заглушки вместо реальных функций.

Главный приоритет — качество анализа книг, а не количество декоративных элементов.

Итог: создать продукт, который превращает чтение книг в интерактивный образовательный опыт.
