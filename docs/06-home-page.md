# Этап 4. Главная страница

## Что сделано

| Задача из [плана](04-roadmap.md) | Результат |
|---|---|
| Инициализация проекта | Next.js 16 (App Router), TypeScript, Tailwind CSS 4, ESLint, Prettier, Vitest, Playwright, проверки в GitHub Actions (`.github/workflows/ci.yml`) |
| Дизайн-токены и темы | `src/styles/tokens.css` — все цвета из [дизайн-системы](02-ux-ui.md); тёмная тема по умолчанию, светлая — по переключателю в шапке, выбор сохраняется |
| Базовые компоненты | `src/components/ui/`: кнопка, поле ввода, карточка книги, метка происхождения, заглушки загрузки |
| Макеты | Главная — сама страница и снимки ниже; презентация — макет на холсте Claude Design (десктоп в светлой теме и телефон в тёмной), хранится в артефактах владельца проекта |
| Главная | Заголовок, поле поиска, «Как это работает», «Как мы работаем с источниками» |
| Страница результатов | `/search?q=…` принимает запрос и честно сообщает, что каталог подключается на этапе 5 |

Блок «Примеры готовых презентаций» входит в MVP и появится на главной, когда будут готовые анализы (этап 6). «Популярные книги», «Моя библиотека», загрузка файла и вход в аккаунт отнесены к версиям после MVP. До появления данных и функций эти элементы не показываются: кнопок без функции в интерфейсе быть не должно.

Тексты главной следуют фокусу продукта: знания, а не пересказ — анализ, критика, связи и действие.

## Критерии готовности

| Критерий | Как проверяется |
|---|---|
| Главная корректна на 360, 768, 1280 и 1920 px в обеих темах | Playwright: восемь прогонов, проверка отсутствия горизонтальной прокрутки и видимости всех блоков, снимки экрана |
| Поле поиска ведёт на страницу результатов | Playwright: отправка кнопкой и клавишей Enter; пустой запрос и запрос из пробелов не отправляются |
| Контраст текста не ниже 4.5:1 | Модульный тест считает контраст каждой пары «текст — фон» по формуле WCAG прямо из файла токенов; axe-core проверяет готовую страницу в обеих темах |
| Вся страница проходится с клавиатуры | Playwright: порядок фокуса, видимая обводка, ссылка «Перейти к содержимому» |
| Нет элементов без функции | Каждая ссылка и кнопка страницы участвует в сценарных тестах |

Дополнительно проверяются: области нажатия не меньше 44 × 44 px на телефоне, отсутствие ошибок в консоли браузера, сохранение темы после перезагрузки.

Всего 96 модульных и 20 сценарных тестов.

## Принятые решения

1. **Тёмная тема — основная**, как решено в [«Фокусе продукта и MVP»](05-focus-and-mvp.md). Каждый токен — пара значений `light-dark()`; страница открывается тёмной, а когда пользователь выбирает светлую, на `<html>` ставится `data-theme`. Короткий скрипт в `<head>` применяет сохранённый выбор до первой отрисовки, поэтому страница не мигает. Системная настройка темы не учитывается: иначе большинство посетителей увидели бы не основную тему.
2. **Шрифты лежат в проекте** (пакеты Fontsource), а не загружаются с Google Fonts: сборка не зависит от внешней сети, а браузер посетителя не обращается к сторонним серверам.
3. **Снимки экрана не сравниваются попиксельно.** Отрисовка шрифтов различается между системами, и такие тесты давали бы ложные срабатывания. Вместо этого проверяются измеримые свойства (прокрутка, видимость, контраст, размеры), а снимки сохраняются для просмотра.
4. **Стандартная палитра Tailwind отключена.** В классах доступны только цвета дизайн-системы — случайный цвет вне токенов не появится.
5. **Форма поиска работает без JavaScript**: это обычная форма с методом GET; при включённом JavaScript переход происходит без перезагрузки страницы.
6. **Два новых токена**: `--border-strong` (граница полей — контраст с фоном не ниже 3:1) и `--on-accent` (текст на акцентной кнопке). Добавлены в таблицу дизайн-системы.
7. **Motion и React Flow пока не подключены**: на главной хватает CSS-анимации, библиотеки появятся вместе с презентацией (этап 7).

## Решения для этапа 5

- Поиск начинается с кэша в памяти за интерфейсом хранилища; база Supabase подключается позже без переделки кода.
- В запросах к Open Library приложение представляется названием и адресом репозитория, без личной почты.
- Загрузка файлов ждёт хранилища Supabase.

Это совпадает с объёмом MVP: загрузка файлов и анализ по полному тексту отнесены к версии 1.2.
