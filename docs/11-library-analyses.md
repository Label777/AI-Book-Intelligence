# Готовые анализы

Платный ключ AI API не подключён, поэтому движок (этап 6) на сайте не запускается.
Чтобы на сайте были настоящие анализы, а не заглушки, часть их готовится заранее и
хранится в репозитории как данные. Показывает их тот же компонент презентации, что и
результаты движка, — поэтому они работают и на сервере, и в статической версии на GitHub Pages.

## Как готовится анализ

1. Источники: описания издательств, библиотечные каталоги (оглавление), рецензии
   (The Observer, Moment, Kirkus, E-IR, Австралийский институт международных отношений и др.).
2. Каждый источник получает короткие выдержки — **пересказ по-русски**, не дословные цитаты.
3. Утверждения делятся по происхождению, как в движке:
   - «Факт из книги» — что о содержании книги сообщают источники; ссылка на выдержку обязательна;
   - «Внешние исследования» — сведения об авторе, других книгах, мнения рецензентов;
   - «Интерпретация AI» и «Критика» — выводы; у каждого перечислено, на каких фактах он стоит.
4. Каждое утверждение показано один раз; повторы и «висячие» утверждения запрещены.
5. Текста книги нет — разбор глав строится по оглавлению, описаниям и рецензиям, без сцен и цитат.
   Это указано на обложке, в разборе глав и в окне «Как сделан этот анализ».

## Код

- `src/library/author.ts` — `AnalysisBuilder`: источники, факты, выводы, действия, слайды.
- `src/library/analyses/*.ts` — сами анализы.
- `src/library/index.ts` — список анализов и поиск анализа для книги из каталога
  (по названию и автору на любом языке).
- `src/library/validate.ts` — проверка: схема, ссылки на выдержки, основания выводов,
  схемы, действия, все разделы ТЗ, отсутствие повторов.
- `src/app/library/[slug]/page.tsx` — страница; собирается заранее (`generateStaticParams`).
- В окне источника для таких анализов: «Что сказано в источнике (пересказ)» и
  «Сверено с источником при подготовке анализа».

## Где видно на сайте

- Главная: блок «Готовые анализы» и ссылка «Анализы» в шапке.
- Страница книги (сервер и статическая версия): если для книги есть готовый анализ —
  кнопка «Открыть анализ».

## Проверки

- `tests/unit/library.test.ts` — каждый анализ проходит `validateAnalysis`; структура ТЗ
  (5–10 идей, 10 инсайтов, 10 выводов, 6 оценок, план на 24 часа / 7 / 30 дней);
  выдержки короткие; поиск анализа по английскому и русскому названию.
- `tests/e2e-static/static.spec.ts` — анализ открывается без сервера, слайды листаются,
  окно источника показывает пересказ, «← К книге» ведёт в поиск каталога.

## Как добавить книгу

Создать `src/library/analyses/<slug>.ts` по образцу, добавить запись в `LIBRARY`
(с названиями на других языках в `aliases`) и запустить `npm run check`.
