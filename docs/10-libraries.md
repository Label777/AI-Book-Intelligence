# Открытые библиотеки

К сайту подключены десять бесплатных легальных онлайн-библиотек. На странице книги есть блок «Где читать и слушать», на главной — их список.

## Какие библиотеки и как подключены

| Библиотека | Что в ней | Подключение |
|---|---|---|
| Open Library | Каталог книг, выдача электронных копий на время | Проверка наличия |
| Internet Archive | Отсканированные книги, свободные для чтения | Проверка наличия (через Open Library) |
| Project Gutenberg | Классика в общественном достоянии | Проверка наличия (каталог Gutendex) |
| Google Books | Полные тексты старых книг, фрагменты новых | Проверка наличия |
| Standard Ebooks | Выверенные издания классики на английском | Ссылка на поиск книги |
| LibriVox | Бесплатные аудиокниги | Ссылка на поиск книги |
| Викитека | Свободные тексты; раздел выбирается по языку названия (uk, ru, en) | Ссылка на поиск книги |
| HathiTrust | Оцифрованные фонды университетских библиотек | Ссылка на поиск книги |
| DOAB | Научные книги в открытом доступе | Ссылка на поиск книги |
| Europeana | Оцифрованные книги библиотек Европы | Ссылка на поиск книги |

**Проверка наличия** — сайт сам спрашивает библиотеку, есть ли в ней именно эта книга, и показывает прямую ссылку: «Читать бесплатно», «Взять почитать на время» или «Читать фрагмент». **Ссылка на поиск** — у библиотеки нет программного доступа из браузера, поэтому сайт открывает её поиск с названием и автором книги.

Список и адреса — в `src/books/libraries.ts`; добавить библиотеку значит добавить запись туда.

## Как отбирались

В список попали библиотеки, которые бесплатны, работают легально (общественное достояние, открытые лицензии, выдача с согласия правообладателей) и дают устойчивый адрес поиска. Теневые библиотеки (LibGen, Z-Library, Anna's Archive и подобные) не подключаются: они распространяют книги без разрешения правообладателей.

Украинские волонтёрские библиотеки (Чтиво, УкрЛіб) пока не подключены: у них нет программного доступа, а адреса поиска я не смог проверить. Украинские тексты в общественном достоянии находятся через украинский раздел Викитеки.

## Что важно знать

- Проверки идут из браузера посетителя, каждая независимо. Если библиотека не ответила, по ней остаётся ссылка на поиск, страница не ломается.
- Совпадение проверяется строго: название должно совпасть по словам в обе стороны, фамилия автора — тоже. Пересказы и одноимённые книги других авторов не засчитываются.
- Ссылки на найденные копии строятся только на адреса самих библиотек; чужие адреса из ответов отбрасываются.
- Современные книги под авторским правом в этих библиотеках обычно доступны фрагментом (Google Books) или на время (Open Library). Полного текста бесплатно у них, как правило, нет — и сайт этого не обещает.
- Тексты книг сайт не хранит и не показывает: он только ведёт в библиотеку.

## Проверка на выложенном сайте

После каждой публикации GitHub Actions открывает выложенный сайт в настоящем браузере, ищет «Pride and Prejudice», открывает книгу и записывает в аннотации к запуску, что нашлось в библиотеках и как ответила каждая из них (`tests/live/site.spec.ts`).

Что показала проверка 17 ноября 2026 года:

| Что | Результат |
|---|---|
| Поиск по Open Library из браузера | Работает: 10 результатов, страница книги с годом и числом изданий, обложка загружается |
| Open Library и Internet Archive | Работает: найдена свободная копия в Internet Archive |
| Google Books | Не подтверждено: сервис разрешает запросы с сайта, но с адреса GitHub Actions ответил «слишком много запросов» (429). У обычного посетителя лимит свой, но проверить это отсюда нельзя |
| Project Gutenberg | Не работает: каталог Gutendex не ответил браузеру за отведённое время. По этой библиотеке остаётся ссылка на поиск |

Каждая библиотека проверяется отдельно, поэтому найденное в одной показывается сразу, а не ждёт остальных.
