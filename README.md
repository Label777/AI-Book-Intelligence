# AI Book Intelligence

Платформа, которая извлекает из книги знания, а не пересказывает её: анализ идей, критика, связи с другими книгами и план действий — в виде интерактивной презентации. У каждого утверждения видно, откуда оно взято.

**Первая версия (MVP):** вводишь название книги — получаешь презентацию из 14–20 слайдов с глубоким разбором.

## Статус

Готовы этапы 1–4: исследование, проектирование интерфейса, архитектура и главная страница. Приложение запускается, поле поиска ведёт на страницу результатов; сам поиск по каталогу книг — следующий, пятый этап.

| № | Этап | Статус |
|---|---|---|
| 1 | Исследование продукта и конкурентов | ✅ |
| 2 | UX/UI и проектирование интерфейса | ✅ |

## Запуск

Нужен Node.js 22 или новее.

```bash
npm install
npm run dev          # http://localhost:3000
```

| Команда | Что делает |
|---|---|
| `npm run dev` | Режим разработки |
| `npm run build` и `npm run start` | Сборка и запуск рабочей версии |
| `npm run check` | Линтер, форматирование, типы и модульные тесты одной командой |
| `npm run test` | Модульные тесты (Vitest) |
| `npm run test:e2e` | Сценарии и адаптивность (Playwright); перед запуском нужна сборка |
| `npm run format` | Форматирование кода (Prettier) |

Для сценарных тестов один раз установите браузер: `npx playwright install chromium`. Те же проверки выполняются в GitHub Actions при каждой отправке в репозиторий.

## Структура

```
src/app/          страницы: главная, /search, 404
src/components/   интерфейс: ui/ — базовые компоненты, home/ — блоки главной
src/books/        поиск и идентификация книг
src/pipeline/     AI-движок анализа: шаги, проверки, клиент модели
evals/            контрольные книги и прогон на настоящей модели
src/lib/          общие утилиты: тема, метки происхождения, контраст
src/styles/       дизайн-токены
tests/unit/       модульные тесты
tests/e2e/        сценарии Playwright
docs/             документация по этапам
```

## Ключевые принципы

- **Четыре типа утверждений:** факт из книги, интерпретация AI, внешнее исследование, критический вывод. Тип хранится в данных и показывается в интерфейсе.
- **Два режима анализа:** по полному тексту (файл пользователя) и по открытым источникам. Режим всегда виден.
- **Ничего выдуманного:** нет подтверждённого оглавления — нет разбора по главам; нет точного совпадения — нет цитаты.
- **Генерация в восемь шагов** с сохранением промежуточных результатов и отдельной проверкой фактов.
- **Действие у каждой идеи:** не только «что написано», но и «что с этим делать».

После MVP: сравнение авторов по теме и персональный интеллектуальный профиль.

## Стек

Уже в проекте: Next.js 16 (App Router) + TypeScript, Tailwind CSS 4, Vitest, Playwright. Подключаются на следующих этапах: PostgreSQL с pgvector (Supabase), Inngest для фоновых задач, Claude API, Open Library для метаданных. Обоснование — в [архитектуре](docs/03-architecture.md).
